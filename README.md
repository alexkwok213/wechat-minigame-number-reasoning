# 高智商数字推理 · 密码推理

> 微信小游戏 · Mastermind（Bulls and Cows）式数字推理 · 纯 Canvas 2D 实现

一款单机离线的数字推理休闲益智游戏。系统随机生成一组**数字不重复**的隐藏密码，并给出一组"错误尝试"线索卡，玩家据此逐轮排除、缩小范围，推理出唯一密码。

## 玩法

前 3 关为 3 位密码，第 4 关起升级为 4 位。每张线索卡显示一组猜测数字及其反馈：

| 反馈文案 | 含义 |
|---|---|
| 所有数字都不正确 | 0 对 |
| 两个数字正确，但位置都不正确 | 2 对 0 中|
| 三个数字正确，其中一个位置也正确 | 3 对 1 中 |

玩家上下滑动顶部**黄铜数字轮**逐位调整 0-9，松手自动吸附，然后点「解锁」验证。**所有线索卡保证唯一解**，不会遇到死局。

## 功能

- **闯关**：逐级解锁，每关重新随机生成谜题（保证唯一解）
- **提示**：锁定一位正确数字，扣除本关15 分
- **积分**：每位密码 40 分，超时每秒扣 1 分，单关保底 10 分，本地存档
- **音效**：`wx.createWebAudioContext()` 实时合成，无需外部音频文件
- **规则弹层**：内置玩法与计分说明
- **竖屏适配**：顶部自动避让状态栏 / 刘海 / 右上系统胶囊，底部避让home 指示条

## 运行

1. 打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「小游戏」项目类型
3. 导入本目录（`project.config.json` 已内置`compileType: "game"`）
4. 点击编译即可预览

> 直接把仓库克隆到本地、导入开发者工具即可运行，无需额外依赖或构建步骤。

## 技术说明

这是一个**微信小游戏（Mini Game）**，不是小程序（Mini Program）：

- 入口为 `game.js` + `game.json`，**没有** `app.json` / WXML / WXSS / pages 目录
- 全部画面用 Canvas 2D 逐帧绘制，无 DOM
- 存档走 `wx.setStorageSync`（key `mmTuiLiSave`）
- 布局集中在 `computeLayout()`，改外观优先改这里，避免散落的魔法数
